# FR-05: Input Conversazionale e Vocale (Soli Assistant)

Il sistema deve integrare un modulo LLM (Large Language Model) che permetta all'utente di formulare richieste tramite linguaggio naturale o comandi vocali, estraendo automaticamente le entità (tipo di servizio, data, luogo) per pre-compilare il form di richiesta (Modalità "No-UI").
