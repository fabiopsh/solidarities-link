# FR-01: Autenticazione tramite Identità Digitale

Il sistema deve permettere la registrazione e l'accesso degli utenti (Volontari e Richiedenti) esclusivamente tramite integrazione con sistemi di identità digitale pubblica (SPID/CIEid/servizi di emulazione di registrazione) per garantire la certificazione dell'identità (Livello di fiducia LV1).
